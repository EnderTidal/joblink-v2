What JobLink does

JobLink finds you self-selected, interested candidates - zero cold calls. You'll do everything through the Wizard — a chat with four buttons: create job orders, send Magic Blasts (a text with each candidate's personal job link), review results, and get help.

This setup walks you through connecting your messaging provider so blasts can actually send texts. Connect your messaging provider so blasts can send real texts.

JobLink works best when you have:

✓ 5+ open job orders
✓ 200+ candidate phone numbers
✓ High-volume roles (industrial, warehouse, skilled trades)
✓ Recurring fills (not one-off placements)

The bigger your candidate pool, the better your results.

Connect Your Messaging

JobLink sends texts through Whippy. All you need is your API key — we'll auto-detect everything else.

Get your API Key

  1. Log into Whippy
  2. Go to Settings (gear icon) → Developers
  3. Click + Add key, name it JobLink, then copy it
Settings sidebar — scroll down to find Developers
Developers → API keys — click the copy icon to grab your key
Paste your API Key here ↓

Select your sending numbers

Click a number to move it between columns. Selected numbers will be used for blasts.

Select at least one number to continue.
